# Privacy Policy

**Last updated:** October 2026

This Privacy Policy explains how **[Nome do Bot]** ("the Bot") collects, uses, and safeguards information when operating within Discord servers.

## 1. Information We Collect
To function properly, the Bot may process and store the following minimal data:
- **Discord IDs:** User IDs, Server (Guild) IDs, Role IDs, and Channel IDs to manage permissions, user configurations, and departmental/server settings.
- **Bot Interactions:** Command parameters, slash command inputs, and interaction metadata strictly necessary to execute requested actions.
- **Operational Logs:** Timestamps and error logs for debugging and system stability.

> **Note:** The Bot does **not** read, monitor, or store personal direct messages (DMs) or general server chat messages outside of direct command interactions.

## 2. How We Use the Information
Collected data is used exclusively to:
- Deliver and maintain the core functionalities of the Bot.
- Maintain persistent configurations and roles per guild/user.
- Diagnose technical issues and prevent abuse/spam.

## 3. Data Sharing and Third Parties
- We **do not** sell, rent, monetize, or trade any collected data to third parties.
- Data is only accessible to authorized developers and maintainers of the Bot, hosted securely on our operational database/servers.

## 4. Data Retention and Deletion
- Data is retained only as long as necessary to provide service to the user or server.
- If the Bot is removed from a server, associated configuration data may be deleted automatically or upon periodic cleanup.
- **Right to Erasure:** Any user or server owner may request immediate and permanent deletion of their stored data by contacting us.
